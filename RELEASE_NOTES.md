# JTransient Release Notes

## 1.0.6 (unreleased)

- **Too few frames stop the run after quality control.** When quality control keeps fewer than three frames (`JTransientEngine.MIN_KEPT_FRAMES`), `runPipeline` now stops there and returns a completed result marked with the new `PipelineResult.tooFewFrames`, holding the quality-control telemetry, the drift points and the data area. Before, it went on with one or two frames: the tracker already returned no tracks, but the stacks, slow movers and photometry still ran, and SpacePixels rewrote the result afterwards. With no frame kept, the run used to fail at the master reference; it now returns this result too. The stage observer hears no stage in that case. `PipelineResult.Builder.tooFewFrames` sets the field. Runs that keep three or more frames are unchanged.
- **Stage observer (JA-09).** A new `runPipeline(frames, config, listener, providedMasterStack, observer)` overload hands each finished stage (`PipelineStage`: master reference, slow movers, tracking, common motion, residual analysis, photometry) to a `PipelineStageObserver` with that stage's own products. The observer is called on the pipeline thread; its exceptions are reported and ignored. Results are unchanged with or without one.
- **Track linker split into stage classes (JA-06).** `TrackLinker` now orchestrates package-private stage classes; its public results and the detection results are unchanged.
- **The legacy score-based tuner is removed (JA-08).** `JTransientAutoTuner`, its options, the `LEGACY_TUNING` stage ID and the `AUTO_TUNE` rules scope are gone; `CalibratedAutoTuner` is the only tuner. `AutoTuneProfile` and `AutoTunerResult` are now top-level types in `engine`. `AutoTunerResult.bestTransientRatio` is renamed `noisePerMpixFrame`, and the fields only the legacy tuner filled (`bestStarCount`, `finalValidationTelemetry`, `effectiveOptions`) are removed.
- **Structured failures.** Engine and tuner calls throw `OperationFailedException`, which names the stage and the original frame where the failure happened, apart from completed empty or insufficient-evidence results and from joined cancellation. Stage IDs and frame identities are carried through worker batches, listeners, photometry and tuning. Interruption retains its flag; fatal errors propagate. Per-stage progress/outcome events remain separate JA-09 work.

- **Independent tuner operations.** The tuner captures immutable options, defensively copies grids/budgets and retains effective policy provenance. Explicit options support concurrent independent requests.
- **One worker pool per engine (JA-12).** Each engine, and each tuner call, owns a library-internal `WorkerPool` that runs its batches, stack rows and photometry within a scratch-memory estimate; nested batches run inline and a failure or cancellation joins sibling work. Removed, because no caller used them: borrowed executors and shared sessions (`ExecutionSession`, `ExecutionPolicy`, the engine constructors taking them), `OperationOutcome` and `OperationContext.capture`, the `CancellationToken` overloads of `runPipeline`, `detectTransients`, `generateMasterStackWithDetails` and `CalibratedAutoTuner.tune`, the tuner's `executionPolicy` option and session overloads, the executor parameter of `VariableStarAnalyzer.analyze`, and the deprecated `CommonMotionRejector.apply`. Cancel through `CancellationScope`. Outside an engine or tuner operation, standalone batches run on the calling thread.
- **Java and compatibility gates.** Java 21 toolchain/`--release 21` and bytecode checks for adopted config/execution boundaries run under `check`; the API consumer runs when the Central bundle is prepared. The coordinated SpacePixels matrix verifies source-built 1.0.5/1.0.6 artifacts with composites disabled and both Gradle/POM metadata. The 1.0.5 section below describes the predecessor unreleased source baseline, not a publicly available artifact; actual Central release availability remains unverified. No publication is performed by these checks.

## 1.0.5 (unreleased)

In preparation: changes since 1.0.4 are collected here and completed at release. Used by SpacePixels 2026.10-04.

### Detection changes

- **Anomalies on a streak's path join that streak.** A faint streak crossing a star changes the star's shape, and a tumbling satellite flashes along its path. Both were rescued as single-frame anomalies. An anomaly on a confirmed streak's line in the same frame, or where the streak's motion puts it in a frame the streak skipped or in the frame just before or after it, is now a piece of that streak. See [Anomalies on a streak's path](ALGORITHM.md#134-anomalies-on-a-streaks-path).
  - On the reference data, klangwolke-2 kept 22 of its 39 anomalies. The joined pieces were mostly a satellite's flashes and a trail crossing stars. The other datasets were unchanged, apart from one anomaly on klangwolke-1.
  - Photometry flags the stars a track crosses, so the stars these pieces cross lose their measurement in those frames.

### API changes

- **JA-01: captured configuration and shared rules.** Engine operations, both tuners and direct calibration capture private settings before processing. `DetectionConfigRules` exposes metadata for all 107 fields, operation-scoped structured validation and explicit alignment with field/rule IDs and adjustment directions. Non-finite consumed values are errors; finite legacy values, sentinels and scientific-policy conflicts remain accepted with advice. No serialized config fields/defaults change.
- Both tuners add `tuneSnapshot(...[, cancellation])` with detached fallback configs. Existing `tune` overloads preserve the same-reference fallback contract. SpacePixels consumes the rules for GUI, profiles, API and iterative requests. This is a coordinated local source integration; published-pair compatibility still needs release validation.
- `PhotometryGeometry` centralizes existing effective aperture/annulus pixel margins and exposes structured radius adjustments. Selection and crossing checks now follow expanded measurement radii instead of raw factors; configured factors remain unchanged. Targeted edge/crossing/flux tests cover custom/legacy factors. On the 153-frame africano-reg reference sequence, full scientific snapshots remain byte-identical to the pre-JA-01 baseline (excluding execution timings, hashing image/mask arrays).

- `TrackLinker.AnomalyDetection.lowConfidence` is removed. The anomalies it marked, those on a streak in the same frame, are now pieces of that streak's track in `PipelineResult.tracks` instead of entries in `PipelineResult.anomalies`.
