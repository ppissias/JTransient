# Exact computation reuse amendment

Historical investigation snapshot. Statements about implementation, pending work or publication describe the experiment at its date. Current behavior is documented in [ALGORITHM.md](../../../../ALGORITHM.md); current decisions remain in [FEATURE-REQUESTS.md](../../../../FEATURE-REQUESTS.md). Local artifact names in the snapshot are not promises that every external cache or harness is bundled. See this study's [inventory](README.md).

The six scientific datasets, two tiles, inputs, clocks, truth, policies, gates and900s budget are unchanged. Native K2 from the original frozen implementation remains accepted only after its own parity checks. M81's39,340 coarse motions make repeated identical stacks expensive. Introduce a separately named research copy which reuses only completed preprocessing/coarse best-score/motion arrays within one caller-owned batch. Input identity, geometry, timing, seeing, motion grid, polarity and preprocessing policy must agree. Star-mask, streak-mask and final-clip variants have separate cache entries; the half/clip pair can share the no-clip entry. Local maxima, refinement, half/stationary/camera checks, evidence copying and global selection execute independently for every policy, and all original early rejection counters remain intact. Release each batch cache before advancing context. Incomplete tile results are never cached. Cache timings are diagnostic workload times, not independent production timings or performance improvement estimates for production.

Before accepting any cached native study, require exact all17-policy synthetic cached/uncached candidate/review/counter parity and production baseline parity. Also compare a cached native K2 validation replay across the already completed four all-policy batches with every original uncached candidate, review hash and scientific counter. No tolerance relaxation, gate tuning or changed footprint is allowed. Preserve the first manifest/source/classes/results and any interrupted original job separately. Freeze the amendment/code/classes/runner before cached native execution. All large field JVMs remain sequential.
