## Injections

Each of the two tiles contains three independently labelled source slots at local(128,128),(384,128),(256,384). Six batches cross Gaussian/Moffat PSFs with nominal native integrated-aperture SNR1.5/2.5/4 per frame, calibrated from the first frame's local sky spread at the fixed slot. Gaussian FWHM equals measured search FWHM; Moffat shares that FWHM with beta3.5. Width varies sinusoidally by20% at approximately fixed flux; seven exposure samples integrate the path. No photon noise is added because native gain is not established. Preserve pixel saturation/fill/crop and source-overlap exclusions without relocating cases.

Slots represent slow straight(.12px/min,angle.31), fast straight(.32,1.13), fast gapped(every fifth injection and middle20% absent), mildly curved fast(midpoint bow one measured FWHM), a fast star crossing, and a camera-fixed point. The star crossing uses the highest-flux compact unsaturated native master source inside the second tile's100px inset and at least160px from the other slot paths; absence is an unavailable source, not permission to choose a better location. Reject a source if its active midpoint falls within20 search FWHM of an earlier active injected source. The detector still searches blindly, without injection truth/catalogue positions. Separate bright single-frame batches use six fixed point sources at nominal SNR60, appearing only in the first or middle exposure. These are controlled source mechanisms, not physical magnitude completeness.

Use row-level copy-on-write for injected pixels and recompute the exact lower median only at changed pixels; every unchanged pixel/reference sample remains shared read-only. Validate this median optimization against full median on a synthetic control. Upstream native streak/ordinary-track context and QC are frozen: these are faint-stage sensitivity tests, not end-to-end rediscovery through changed upstream extraction/QC. Score each injected moving source once using midpoint path RMS<=one measured FWHM and motion discrepancy<=.1px/min (or the expected curved mean motion), retaining actual coverage and camera-control labels. More repeated peaks are not extra source recovery. Report time-gaps, masks, source self-subtraction, seeing and unavailable diagnostics separately. Post-selection source truth must not select a peak before the blind search.
