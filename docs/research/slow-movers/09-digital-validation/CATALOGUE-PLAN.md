# SM-F6 candidate-review catalogue plan

Historical investigation snapshot. Statements about implementation, pending work or publication describe the experiment at its date. Current behavior is documented in [ALGORITHM.md](../../../../ALGORITHM.md); current decisions remain in [FEATURE-REQUESTS.md](../../../../FEATURE-REQUESTS.md). Local artifact names in the snapshot are not promises that every external cache or harness is bundled. See this study's [inventory](README.md).

Review the11 saved full-field Klangwolke-2 findings, including the five without a compatible saved prediction. Preserve the existing report and its six named comparisons. The post-detection catalogue query does not enter any blind detector, tune its motion grid or label a discovery.

Use the existing SolarSystemClient and its supported magnitude limit23. Query fixed256px square fields centred on FM4,FM8,FM9,FM10,FM11 and the previously matched FM2 positive comparison. Keep the native observing span, header-derived observer and original WCS; transform crop CRPIX consistently, without writing FITS files. Record limits, field scope, fetch/source versions, missing-magnitude selection, supplied uncertainties, partial fetch/fallback status and ambiguous associations. Catalogue absence is not a new-object or false-detection verdict. No fallback to this machine's home observing site for another dataset. A missing observer is unavailable evidence.

Use the admitted report's WCS/correction for comparisons, actual exposure midpoints and saved fitted positions. Compare all candidate bodies, not only the nearest name, and keep uncertainty/position/rate/coverage separate. A broad uncertainty cannot identify a track. Retain raw cached prediction products privately; publish no observer coordinates, request URLs containing a site, private paths or settings. Do not modify original solar_system.json, reports or home preferences.

Freeze this plan, request targets, code, dependency and source hashes before querying. Deeper queries on candidate-local fields are intentionally candidate review, not a complete deeper inventory or detection completeness experiment. The broader matched-domain null/injection study has its own frozen execution plan.
