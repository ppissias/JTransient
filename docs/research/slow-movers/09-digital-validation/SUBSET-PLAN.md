# Disjoint image-thirds blind searches

Historical investigation snapshot. Statements about implementation, pending work or publication describe the experiment at its date. Current behavior is documented in [ALGORITHM.md](../../../../ALGORITHM.md); current decisions remain in [FEATURE-REQUESTS.md](../../../../FEATURE-REQUESTS.md). Local artifact names in the snapshot are not promises that every external cache or harness is bundled. See this study's [inventory](README.md).

Catalogue associations and full-fit-centred coadds do not independently rediscover a source. As a separate fixed validation, use the current QC-retained K2 frames split chronologically into disjoint9/9/10-frame thirds. Within each third rebuild the exact native median, retain its own measured seeing metrics and corresponding streak lists, restrict ordinary tracks to that third's original frame identities, and search every original grid tile blindly with unchanged scientific defaults and900s safety budget. Retain the full-session common data area/registrations as upstream context; these conditional subsets are not independent nights or significance tests. No truth/catalogue position seeds proposals and no score/motion threshold is lowered for weak subsets. Compare all11 original full-search paths after search at path RMS<=that subset's FWHM and motion error<=.1px/min; retain positional competitors and searched coverage. Label each expected full path outside the subset's nominal motion range separately, without calling a non-recovery a false object. Search eligibility/weak full-threshold power can limit this review. Frozen before execution, after the deeper catalogue review; it validates existing detections rather than selecting a new rule. Run after the six-field study, never concurrently with another large JVM.
