## Validation attached to the deliveries

- Row-cache/centroid deliveries pass 364 engine tests plus the API consumer and application checks/API consumers with 763 tests and seven existing skips. Eighteen reference datasets preserve legacy science and 5,310 existing assets; stack/mask hashes and raw input ownership are checked. Centroid review intentionally adds exports/panels rather than changing accepted findings.
- Bounded faint-mover review reproduces all eleven K2 candidates/cutouts with 28-frame evidence each; half-map maxima reproduce half scores. Progress delivery verifies identical science/assets with previews shown or hidden. The shown run records 35 previews at a mean interval of 3.13 s; the timing comparison is not a controlled overhead benchmark.
- The final known-object report commit records 790 application tests with seven existing skips, 46 JavaScript checks, both API consumers and packaging checks. Nineteen real-data comparisons preserve science/stacks/masks and legacy assets (5,346 across eighteen off-mode reports and 440 in the full faint-search report). All 818 original images are unchanged. Browser layout review for that final revision was unavailable because the active URL could not be verified; the commit does not claim it passed.
- The later documentation-only SM-F6 study verifies 744 production/build/test source hashes unchanged, all 818 original images unchanged, exact production/research parity, all 77 original/cached K2 cases and all 462 selected-domain searches. Existing application/unit suites are not redundantly rerun for this publication.

Test counts refer to their recorded delivery revisions and must not be combined into a new run total.

## Alternatives that remain research

No universal correlation or three-bin veto, wider default axis ratio, automatic maximum-stack deduplication, residual-fit replacement, covariance-confidence gate, star-mask/clipping removal or lower default score is adopted from these experiments. Gains/losses, controls, unavailable cases and counterexamples are retained in the study folders.

The deeper catalogue review supplies compatible paths for all eleven original K2 candidates; it does not change detections/reports or calibrate identity confidence. SM-F1/P1/P2/P3 and broader SM-F6 validation retain unresolved evidence requirements. SM-F7 temporal-bin and PSF-filtered frame-point methods have historical prototype results, but a new comparison against the current verifier and any integration remain pending. Current decisions are in [FEATURE-REQUESTS.md](../../../FEATURE-REQUESTS.md).
