Dated investigation snapshot. Current behavior remains in [ALGORITHM.md](../../../../ALGORITHM.md) and pending decisions in [FEATURE-REQUESTS.md](../../../../FEATURE-REQUESTS.md). Local executable/cache names describe external diagnostics; see the [retained inventory](README.md).

Prepared after Apophis and part of Africano completed. This is explanatory reuse of the frozen comparison, not independent validation or a new method/threshold selection.

After all four original workers and their source-preservation checks finish, reconstruct every frozen injected batch from the same native input and unchanged generator. Check truth equality and exact digital candidate/review hashes and non-time counters against the original result before using any oracle. Keep original outputs unchanged.

For each available moving history, measure exact-path support, filtered samples, halves and the unchanged local verifier starting at its reference position/motion. Evaluate the local refined peak against the digital blind verified pool using unchanged final selection. Record whether the refined path still associates with the source; a surviving unrelated peak is not a source recovery. Oracle failure is local and does not prove that no other seed can work.

Save bounded native/injected first, middle and last active frame patches for any complete standalone or union gain versus digital, and for the first batch in each field as fixed review examples. Patches contain only pixels, sequence identifiers and image-relative coordinates, with no FITS headers or observing-site metadata. Source truth never enters a blind search. Native arrays and median must remain unchanged.

One isolated 8 GiB JVM per field, serially, after the original study. No production source/settings changes. Freeze this supplement separately before it runs; it must not alter the original execution manifest. Retain every exact replay, unavailability and diagnostic result regardless of whether it supports a proposal method.
