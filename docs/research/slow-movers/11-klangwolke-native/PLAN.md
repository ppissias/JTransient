# Klangwolke-2 native full-field temporal-proposal comparison

Dated research snapshot. See the [inventory](README.md), current [algorithm](../../../../ALGORITHM.md) and [pending decisions](../../../../FEATURE-REQUESTS.md). Diagnostic executables remain external.

Requested after the first SM-F7 matched-verifier study: test the promising temporal-bin complement on the real, uninjected Klangwolke-2 sequence and inspect whether it adds a distinct moving source.

Use the same accepted 33 unsigned-16 input frames, native upstream configuration and largest retained 28-frame session as the recorded eleven-candidate digital baseline. Recompute upstream products and require exact median/maximum/master-mask, kept-frame and ordinary-track parity before interpreting proposals. Search every production core in the full native field, at the admitted speeds through 1 pixel/minute. No artificial sources, catalogue-guided proposals, changed masks or relaxed scientific gates.

Run D, frozen primary T4 and their globally reselected D+T4 union. T4 retains its three count-balanced chronological groups, empirical filtered-residual scale, proposal threshold4, any two groups allowed, production coarse-motion quantization, unchanged complete-sequence refinement and final selection. Reproduce all eleven accepted digital candidates, cutouts, review hashes and non-time counters and compare with the actual library on the same native input. Save blind candidates/proposal/rejection ledgers before catalogue or pixel interpretation.

Full-field resource adaptation is explicitly separate from science. The former two-core harness retained all prepared tiles and proposal records in memory; this run retains at most four cache entries after insertion and streams diagnostic rows to gzip JSONL. Active workers may retain their current tile references. Cache eviction only recomputes identical immutable preparation. Both D and T4 receive the same 3600-second research ceiling (the production 600-second setting is not changed). The frozen 50,000-distinct-seed/core prototype limit remains. Continue other cores after a seed-limited core while global time remains, discarding that incomplete core's partial peaks; record all incompleteness and never infer a miss there. The 1000-candidate ceiling remains. No threshold is retuned after seeing native results.

Require synthetic D actual-library parity and old/new T4/union parity on steady and missing-middle inputs with forced single-entry cache eviction and streamed traces. Source checks preserve the nine original preparation/verifier bodies and the proposal generator after reversing logging-only changes. One large JVM at a time, heap11GiB, four processors/workers, isolated user.home, no GUI or preference access. Freeze programs, dependency/source snapshots, configuration and all33 image hashes before the native comparison.

Associate candidate paths to the baseline using RMS <= one native search FWHM over all searched midpoint epochs and velocity difference <=0.1 px/min; retain all ambiguous matches and near misses. Report route-only candidates, union additions and any displaced baseline paths separately. Compare potential additions with ordinary tracks and accepted maximum-stack supported positions (prior three-position/80%-active/2-pixel criterion), keeping morphology distinct from a moving trajectory. Additional candidate paths are not automatically new physical objects.

Inspect every union addition in unstacked original frames, moving/stationary and disjoint-time coadds, score/half/mask evidence, and neighboring source paths. Coadds use a shared fitted path and are descriptive, not independent rediscoveries. Obtain post-detection known-object predictions when they help distinguish another known asteroid from an alias; unknown/absent catalogue entries do not establish a new asteroid. Preserve all compatible/conflicting paths and unavailable evidence. Existing original reports and caches remain unchanged.

If the native union supplies any additional path, run matched full-field T4/D/union controls on negative residuals and three new clock permutations (seeds2026110571/573/577), subject to the same resource/coverage rules. These are diagnostic controls on existing observations, not confidence calibration. K2 has already been used in development and earlier studies; this is the requested real-data application, not independent threshold validation. Curate findings and limitations in a new dated documentation collection, preserving the ten earlier study directories; no production integration is authorized by this test.
